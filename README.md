# ⚡ Calculadora de Consumo Elétrico

## 📌 Sobre o projeto

O projeto foi desenvolvido na linguagem Python para estimar o consumo mensal de energia elétrica de um aparelho.

O sistema solicita informações simples ao usuário: nome do aparelho, potência e tempo médio de utilização diária.

A partir desses dados, o programa calcula uma estimativa de consumo em **kWh/mês**.

## 🎯 Objetivo

Auxiliar na compreensão do consumo de energia elétrica dos aparelhos utilizados no dia a dia, como TVs, Microondas e etec.

💡 Com a estimativa de consumo, o usuário poderá ter uma ideia do impacto de cada aparelho na sua conta de energia ao final do mês. 

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 🐙 GitHub
